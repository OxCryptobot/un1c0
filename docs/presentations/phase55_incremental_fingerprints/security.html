Fail-Closed Security Properties

1. UEG Validation

Fingerprints never bypass invalid UEG diagnostics. If the AST contains blocking errors, the cache is not queried.

validate() -> bool

2. Semantic Validation

A cache miss always executes the complete Phase 53 semantic validator. Fingerprints optimize identity, not the rules.

validate_ueg_with_profile()

3. Target Capability

Profiles are explicit inputs to the root key. A valid fingerprint for one target cannot authorize unsupported features on another.

TargetCapabilityProfile

The fingerprint is an optimization index. It does not grant authority, persist trust remotely, or replace the compiler's semantic enforcement.
